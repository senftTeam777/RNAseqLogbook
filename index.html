Background¶

Aim¶

Do a differential TE and gene expression analysis comparing experimental and control replicates for each experiment.

Data¶

Data generation: HiSeq: 2x150bp paired End, non-strand-specific (unstranded) library generated using NEBNext® Ultra™ II RNA Library Prep Kit for Illumina® (NEB, Cat: E7770) Genome build: use GRCm38/mm10 mouse reference genome.

Packages and Websites¶

  • FastQC (Quality check). I used version 0.11.9 https://www.bioinformatics.babraham.ac.uk/projects/fastqc/
  • Trim_galore (fastq.gz trimming). I used version 0.6.7. https://github.com/FelixKrueger/TrimGalore/blob/master/Docs/Trim_Galore_User_Guide.md#step-2-adapter-trimming
  • STAR (alignment): I used version 2.7.8a https://github.com/alexdobin/STAR/blob/master/doc/STARmanual.pdf
  • Samtools (index aligned .bam files): I used version 1.15 http://www.htslib.org/
  • TEtranscripts (TE and gene expression analysis): I used version tetoolkit/2.2.1
    https://github.com/mhammell-laboratory/TEtranscripts (this package uses DEseq: https://bioconductor.org/packages/release/bioc/html/DESeq2.html)
  • Bedops (to isolate individual TE genomic locations): I used version 2.4.40 https://bedops.readthedocs.io/en/latest/content/reference/file-management/conversion/gtf2bed.html
  • homer (to annotate individual TE locations from deregulated TE families with nearby genes): I used version 4.11.1 http://homer.ucsd.edu/homer/ngs/annotation.html
  • Conversion ENSEMBL identifiers to gene symbol: https://www.biotools.fr/mouse/ensembl_symbol_converter
  • Venn overlaps: https://bioinformatics.psb.ugent.be/webtools/Venn/
  • GO term analysis: http://geneontology.org/#:~:text=The%20Gene%20Ontology%20(GO)%20knowledgebase,genetics%20experiments%20in%20biomedical%20research
